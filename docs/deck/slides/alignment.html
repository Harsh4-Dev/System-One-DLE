Closest overlaps

REINFORCE: ADAR applies it to a real decision, accuracy against compute cost.

What this shows: most projects implement one architecture from one unit; ADAR combines architectures from all four units and decides between them.

For context, here is how the class projects map onto the syllabus. Most implement one architecture from one unit: style transfer and the R-CNN family in Unit II; captioning, translation, the BERT classifier and the RNN comparison in Unit III; GANs and the RL projects in Unit IV. ADAR draws on all four units at once. It overlaps with three projects: it uses a BERT-family encoder, but as one input among several; it uses RNN, LSTM and GRU, but as experts it chooses between per input; and it uses REINFORCE, but for a real cost-versus-accuracy decision.
