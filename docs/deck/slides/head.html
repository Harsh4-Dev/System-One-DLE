What this shows: the head has only 2.3M parameters and answers in the same typed format as a System-One model: an answer, plus how far to trust each source.

Inside the head, every input becomes a short row of tokens. One STATE token is Laya's reading of the text. Each answer option is a token built from Laya's embedding of the label's written description plus every expert's vote for it. Each expert gets a token saying how sure it is. A small two-layer transformer lets all these tokens attend to each other. Out come three typed answers, in the style of a System-One model: choice, the answer; noul for each expert, the probability that this expert is right on this input, which becomes its routing weight alpha; and act, the probability that the head's own answer is right, which we use to abstain or escalate. The head has 2.3 million parameters.
