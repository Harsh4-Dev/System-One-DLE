The 0.470 prior is the board’s own floor (always predicting the label frequencies); the post and procedure are in submissions/.

What this shows: submit where our result is a real contribution now; RouterArena is where ADAR can earn a rank.

Where should this go? We chose by asking where our real result adds value. First, the typed-decisions benchmark: Laya's fine-tuned checkpoint is listed at 0.766 as self-reported, and the maintainer asked for its KL and Brier. Our run re-ran it independently, so we reply in that discussion with the missing metrics and open a pull request that puts the verified scores on the benchmark's Hub leaderboard. Second, the two trained heads go on Hugging Face with their results, so anyone can check them. The head-turner is RouterArena, a ranked leaderboard for routers between large language models, which is exactly ADAR's idea at a larger scale; that is our next phase because it needs other training data and an API budget. We deliberately do not add a 'Laya plus ADAR-Cal' row: its accuracy, 0.363, is below the board's own prior baseline, so it would look like a weak model even though only the calibration changed.
