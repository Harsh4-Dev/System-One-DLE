Wrap-up

Limits and Next Steps

Limits

  • Text classification only so far
  • Laya stays frozen; only the 2.3M-parameter head trains
  • On Emotion, ADAR does not beat the best syllabus network (Bi-LSTM) significantly
  • Attention’s accuracy gain is not significant
  • ADAR-Cal fixes calibration, not accuracy
  • One train/val/test protocol per dataset

Next steps

  • RouterArena: route between LLMs instead of small networks
  • An image task (CIFAR-10) with CNN experts
  • An echo-state network as a fifth expert
  • A short arXiv write-up

What this shows: the gains are real but bounded; the clearest next win is the same head routing between large language models.

We want to be clear about the limits. Text classification only so far. Laya stays frozen; only the 2.3M-parameter head trains. On Emotion, ADAR does not beat the best syllabus network (Bi-LSTM) significantly. Attention’s accuracy gain is not significant. ADAR-Cal fixes calibration, not accuracy. One train/val/test protocol per dataset.
