What this shows: every model sees the same test rows and the same calibration step, and a claim counts only if its confidence interval excludes zero.

We use two public datasets. AG News: 114,000 training articles in four topics, 6,000 for validation and the official 7,600 for testing. Emotion: 16,000 short tweets in six emotions. We compare ADAR against 13 baselines: 5 scikit-learn models on TF-IDF features, the four syllabus networks and their average, Laya answering zero-shot, a logistic regression on Laya's embeddings, and a stacking model. Every model sees the same test rows and is calibrated on validation data; ADAR is trained with 3 seeds, and every claim needs a 95 percent bootstrap confidence interval that excludes zero. The whole pipeline ran in 63 minutes on Kaggle's free GPUs.
