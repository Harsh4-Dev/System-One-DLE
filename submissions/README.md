## A. typed-decisions (10 minutes)

Full steps with links: [`../docs/LEADERBOARD_SUBMISSION.md`](../docs/LEADERBOARD_SUBMISSION.md), sections 1 and 2.

1. Reply in [discussion #2 "Laya benchmark results"](https://huggingface.co/datasets/LocalLLaMA/typed-decisions/discussions/2),
   where the maintainer asked for KL and Brier from the full distributions: paste `typed_decisions/DISCUSSION.md`.
2. Open a community PR on [`convaiinnovations/laya-typed-decisions`](https://huggingface.co/convaiinnovations/laya-typed-decisions)
   adding `.eval_results/typed-decisions.yaml` (file and PR text in `typed_decisions/eval_results_pr/`), so the row
   appears on the benchmark's Hub leaderboard.

What to say in the presentation: "Our evaluation independently reproduces the published accuracy of Laya's
fine-tuned checkpoint (0.7665 vs 0.766), and we contributed the missing KL, Brier and ECE." Don't claim a rank.

## B. Hugging Face model pages (5 minutes)

1. Open `DEV-HV/adar-head-ag-news` → **Files** → `README.md` → **Edit**, paste
   `huggingface/adar-head-ag-news/README.md`, commit. Same for `adar-head-emotion`.
2. The page now shows an **Evaluation results** box.
3. **Settings → Make public** if the demo audience should open it.

With `HF_TOKEN` set this can be done from code:

```python
from huggingface_hub import HfApi
api = HfApi()
for task in ("ag-news", "emotion"):
    api.upload_file(path_or_fileobj=f"submissions/huggingface/adar-head-{task}/README.md",
                    path_in_repo="README.md", repo_id=f"DEV-HV/adar-head-{task}")
```
