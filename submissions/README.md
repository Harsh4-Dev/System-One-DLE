## A. typed-decisions Discussion (5 minutes)

1. Run the fresh proof run first (`docs/KAGGLE_CLI_SETUP.md`), so the post carries its numbers and
   the p50 latency.
2. Open https://huggingface.co/datasets/LocalLLaMA/typed-decisions/discussions → **New discussion**.
3. Paste `typed_decisions/DISCUSSION.md` (title on the first line). Post.
4. Screenshot the post for the deck. If the maintainers add the numbers to the card, screenshot the row too.

What to say in the presentation: "Our evaluation reproduces the leaderboard's own number for Laya
exactly, and we contributed the missing calibration metrics." Don't claim a rank.

## B. Hugging Face model pages (5 minutes)

1. Open `DEV-HV/adar-head-ag-news` → **Files** → `README.md` → **Edit**, paste
   `huggingface/adar-head-ag-news/README.md`, commit. Same for `adar-head-emotion`.
2. The page now shows an **Evaluation results** box.
3. **Settings → Make public** if the demo audience should open it.

With `HF_TOKEN` set this can be done from code:

```python
from huggingface_hub import HfApi
api = HfApi()
for task in ("ag-news", "emotion"):
    api.upload_file(path_or_fileobj=f"submissions/huggingface/adar-head-{task}/README.md",
                    path_in_repo="README.md", repo_id=f"DEV-HV/adar-head-{task}")
```
